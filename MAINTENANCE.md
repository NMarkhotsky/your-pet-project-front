# Локальна перевірка

Запустіть бекенд із сусіднього `your-pet-project-backend` командою `npm start`, тут — `npm run dev`.

Відкрийте `http://127.0.0.1:3001/your-pet-project-front/`.

Режим розробки використовує локальний `/api` через Vite. Змінна `VITE_API_URL` перевизначає адресу. Production-збірка без неї звертається до попереднього API на Vercel.

Перевірки: `npm run lint`, `npm run build`.

Оновлення: спільний клієнт API; скасування застарілих запитів; видимі помилки й повторна спроба; категорії / пошук / фільтри / пагінація оголошень із URL; виправлення авторизації, збереження профілю та фото; плавні анімації з підтримкою `prefers-reduced-motion`; доступні модальні вікна; поділ збірки на частини.

Повний опис виправлень, резервної копії бази, демоакаунта та відновлення є в `MAINTENANCE.md` сусіднього бекенду. Новини, наявні користувачі й партнери збережені. Замінено лише оголошення та особистих тварин і додано окремий демоакаунт.

Код ще не розгорнуто на хостингу.
